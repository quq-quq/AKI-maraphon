# Ручная разметка ритма

Открыть: **AKI → Rhythm → Manual Beat Editor**. Работает в редакторе, вне Play Mode.

Кнопки FishingGamelan / NagaGamelan открывают независимые файлы в `Assets/Core/Data/Rhythm/Manual`. Они изначально пустые. Существующая разметка и назначение музыки в сценах не меняются.

1. Нажми Play или пробел. Во время прослушивания нажимай **M** на основных слышимых ударах. **A** ставит акцент для дрожания частиц.
2. Нажимай и отпускай клавишу на каждом ударе: удерживание клавиши не создаёт повторных меток.
3. Если ставишь метки чуть поздно, увеличь **Tap correction (ms)**: положительное число вычитается из времени новых живых нажатий. Уже поставленные метки не меняются.
4. Клик по waveform переводит воспроизведение к выбранному месту. Visible seconds приближает участок, View start перемещает его. Follow прокручивает за воспроизведением.
5. Голубые метки M — удары; оранжевые A в нижней полосе — акценты. Перетаскивай метки; выбранную можно поправить числом, стрелками на 10 мс или Shift+стрелками на 1 мс. Delete удаляет выбранную. Ctrl+Z отменяет правки.
6. Shift+клик на свободном месте ставит удар; Alt+клик — акцент. Для акцента доступна Strength 0–1.
7. В списке снизу выбери метку для проверки. Audition when selecting a row проигрывает короткий фрагмент вокруг неё. Space останавливает/продолжает с текущей позиции.
8. Нажми **Save** перед переключением проекта или закрытием Unity.

Формат — существующий `RhythmTrack`: `clip`, отсортированные `beatTimes`, `accentTimes`, соответствующие `accentStrengths`. Время в секундах от начала AudioClip. Для подключения позже можно назначить готовые Manual assets в поля текущей системы ритма. Для игровой проверки требуется минимум два удара. Окно пока не меняет игровую систему и окно допуска выстрела.

Положение воспроизведения берётся из позиции аудио в сэмплах. Задержка аудиоустройства и реакция человека остаются: проверяй короткие фрагменты и двигай метки до совпадения со слышимым ударом. Высота waveform показывает громкость, а основной ритм выбирай на слух.
